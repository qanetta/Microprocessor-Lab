# Microprocessor & Microcontroller Lab

A repository containing lab assignments, source code, and simulation models for the Microprocessor - Microcontroller course.

## 🛠 Tech Stack & Tools
- **Target MCU:** STM32 Series (ARM Cortex-M)
- **IDE:** STM32CubeIDE
- **Simulation:** Proteus Design Suite
- **Language:** Embedded C
